# Numpuz Puzzle Game

A modern sliding puzzle game built using HTML, CSS, and JavaScript.

## Features

- Interactive sliding puzzle gameplay
- Multiple difficulty levels
- Move counter and timer
- Level progression system
- Sound effects and background music
- Save and resume game progress
- Responsive user interface
- Smooth tile animations
- Attractive wooden-themed design

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Play

1. Start the game.
2. Rearrange the numbered tiles by sliding them into the empty space.
3. Place all numbers in the correct order.
4. Complete the puzzle using the minimum number of moves and time.

## Project Highlights

This project was developed as a personal learning project to improve problem-solving skills and gain practical experience in front-end web development. The game includes custom level management, local storage support, sound settings, and an engaging user experience.
